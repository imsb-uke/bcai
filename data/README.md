# data/

This directory holds input data for BCAI workflows. Its contents are not tracked by git.

## libraries/
Prepared compound libraries for virtual screening.
Each library is generated by the `prepare_library` tool and contains:
- `df_ligand.csv` — compound metadata and file paths
- `ligands/` — per-compound `.pdbqt` files ready for docking

To use an existing library, point `run_screening` at the library directory.
To create a new one, provide a CSV with `smiles` and `id` columns to `prepare_library`.
