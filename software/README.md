**Binary files**

Binary files for the following software packages should be downloaded into this directory.

* vina (https://vina.scripps.edu/downloads/)
* smina.static (https://sourceforge.net/projects/smina/files/smina.static/download)
* gnina (https://github.com/gnina/gnina)
* FoldX (https://foldxsuite.crg.eu/) — **requires a free academic license**; download and place the binary here yourself. FoldX files are excluded from version control via `.gitignore`.
